### Code Patterns and Methods

The following code patterns and methods used in this project are commonly found in MonoGame shoot 'em up tutorials:

- **Entity Management System**: Standard pattern for managing game entities (PlayerShip, Enemy, Bullet)
- **Collision Detection**: Circular collision detection using radius-based distance calculations
- **Enemy AI Behaviors**: Coroutine-based behavior system for enemy movement patterns
- **Game State Management**: Switch-based state machine for different game phases
- **Input Handling**: Standard MonoGame input processing for keyboard and mouse
- **Content Management**: MonoGame Content Pipeline for loading assets
